# 像素工作室 · 3A之路

一款目标闯关式的独立游戏工作室经营模拟（放置/挂机养成）。

- **在线游玩**：https://你的用户名.github.io/你的仓库名/ （部署后）
- **本地游玩**：直接浏览器打开 `index.html`
- **策划说明**：见 [design.html](design.html) 或 `策划说明.md`

## 作品简介

这是一个用于游戏运营 / 商业化策划方向求职的作品集 Demo，展示以下能力：

1. **数值设计**：完整的成本/产出曲线、递增系数、目标闯关式关卡数值，且全部可在游戏内"策划调试面板"实时调整、可视化验证。
2. **留存与付费**：离线收益、关卡目标牵引、5 个分层付费点设计，每个机制都有明确的设计意图。
3. **落地能力**：用原生 HTML/CSS/JS 实现的可玩 Demo，无需安装、无需联网。

## 目录结构

```
├── index.html      # 游戏本体（可玩）
├── design.html     # 策划说明（网页版）
├── 策划说明.md      # 策划说明（Markdown 源文件）

```

## 技术说明

- 纯前端，无任何依赖，单文件即可运行
- 进度用 `localStorage` 本地存档，支持离线收益结算
